What & Why

Rebuild a real project, learn multi-agent collaboration

SwarmCraft teaches students how to reproduce HKUDS/Vibe-Trading — an open-source, LLM-powered multi-agent trading system (MIT license, ~32.3k GitHub stars, 5.2k+ forks) — using JiuwenSwarm-style workflows: decompose a goal into tasks, assign roles, spawn members, build a task DAG, and run review loops. The reproduction is the vehicle; the multi-agent skills are the lesson.

The Pedagogy Core

The multi-agent workflow

Every step below is demonstrated live in class. Students copy the pattern, then apply it to a real backtest with their own mini-swarm.

1

build_team

A swarm starts with a goal, not with code. The leader defines the goal; the leader never executes tasks.

→
2

spawn_teammate

Instantiate members with named roles & boundaries: researcher, developer, QA reviewer, doc-writer.

→
3

create_task (DAG)

Tasks declare dependencies (blocked_by) and context passing — a directed acyclic graph of deliverables.

→
4

broadcast

Members only start when told: kickoff over the channel; artifacts land in the shared workspace.

→
5

review / verify

A reviewer gates each deliverable: pass completes it, fail sends it back for rework — only the failed subgraph re-runs.

Meta-insight: the very project students reproduce — Vibe-Trading — ships its own swarm DAG engine with 30 preset teams (e.g. equity_research_team: macro_analyst → sector_analyst → stock_picker → aggregator). Multi-agent collaboration is both the tool and the subject of this course.

Mini-Swarm Exercise

One moving-average backtest, six tasks, one mini-DAG

Team goal: “Run one moving-average crossover backtest with Vibe-Trading’s engine, and produce a 5-line report.” It maps to the repo’s real pipeline — data loader → strategy → backtest engine → metrics/report — and works with zero data API keys.

T1 Install & verifyResearcher
→
T2 Data pathData member
→ T3 Strategy (SMA 20/50)
→
T4 Run backtestDeveloper
→
T5 Review outputsReviewer (may reject)
→
T6 5-line summaryScribe

Dependencies: T1 unlocks everything; T2 & T3 run in parallel; then T4 → T5 → T6. A “bad” backtest is a successful exercise if the review loop caught it.

Project-Wide Constraint

No OpenAI GPT models — anywhere

Every LLM component of the reproduction and the course runs on DeepSeek or open-source models. Vibe-Trading is provider-agnostic, and the course configures only non-OpenAI endpoints — verified by vibe-trading provider doctor in the real run above.

deepseek-chat deepseek-v4-flash-0731 Ollama qwen2.5:7b / 3b OpenRouter → deepseek/*

Offline classrooms can run fully key-free with Ollama; online classrooms need only one DeepSeek API key — market data requires no keys at all.
